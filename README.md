# Relayform

**Relayform** — сервис, который принимает данные формы обратной связи или заявки с сайта и быстро передаёт их в выбранный канал команды: Telegram, ВКонтакте, MAX или e-mail.

Дополнительно сервис даёт готовые механизмы подтверждения e-mail и номера телефона, чтобы клиентские формы и регистрация были надёжнее без отдельной интеграции с каждым провайдером.

## Для кого

- Владельцы лендингов и небольших сайтов.
- Маркетинговые и продажные команды, которым важно не пропускать лиды.
- Разработчики, которым нужна единая API-интеграция для доставки заявок и верификации контактов.

## Как это работает

1. Посетитель сайта заполняет форму обратной связи или заявку.
2. Сайт отправляет введённые данные в API Relayform.
3. Relayform валидирует и сохраняет событие, затем доставляет сообщение в настроенные каналы.
4. При необходимости API отправляет код или ссылку для подтверждения e-mail либо телефона и сообщает результат проверки.

## Ключевые возможности MVP

- HTTP API и вебхуки для приёма заявок.
- Несколько каналов доставки на один проект: Telegram, VK, MAX и e-mail.
- Настройки маршрутизации, шаблоны уведомлений и журнал доставок.
- Подтверждение e-mail по 15-минутной одноразовой ссылке с проектным шаблоном и безопасным redirect.
- Подтверждение телефона одноразовым кодом через поддерживаемого провайдера сообщений.
- Личный кабинет: проекты, ключи API, каналы, события и статусы.
- Повторная доставка при временных ошибках и базовая защита от спама.

## Рабочее название

Название соединяет две идеи: **form** — входящая заявка и **relay** — её быстрая передача в нужный канал. Оно короткое, понятно читается и не ограничивает сервис одним мессенджером.

Перед выходом на рынок нужно отдельно проверить доступность домена и товарного знака.

## Статус

Реализована исполняемая основа Next.js/Fastify: кабинет, формы и назначения, 30-дневная статистика, durable очередь с отдельным production worker и аудируемым ручным replay, Telegram/VK/MAX/e-mail активация и доставка, а также подтверждение e-mail через Resend. Следующие этапы — подтверждение телефона и расширенные операционные метрики.
