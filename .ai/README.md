# AI workspace

Единая точка для правил, SDD-спецификаций и проектных навыков.

- `project-rules.md` — обязательные договорённости проекта.
- `context/` — актуальный продуктовый, технический и дизайн-контекст; read first.
- `sdd/` — спецификации и план реализации до написания кода.
- `skills/frontend` — минимальный навык реализации интерфейса.
- `skills/review` — правила frontend и design review.
- `skills/designer` — правила работы с интерфейсом и Figma.
- `references/` — проверенные источники и стек.
