# Spec-driven development

До реализации существенной функции создать спецификацию в `sdd/<featureName>.md`.

Спецификация должна содержать: цель и scope, пользовательские сценарии, UI-состояния (loading, empty, error, success), модель/контракты API, затрагиваемые FSD-слайсы, acceptance criteria и план проверок. Реализация начинается после согласования спецификации; изменения scope обновляют её в том же pull request.
