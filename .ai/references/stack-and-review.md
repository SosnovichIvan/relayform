# Stack and review references

## Chosen stack

Next.js App Router + React + TypeScript + Tailwind CSS v4 + FSD.

## Sources

- [FSD slices and segments](https://fsd.how/docs/reference/slices-segments/): domain-oriented slice names and public APIs.
- [Next.js App Router project structure](https://nextjs.org/docs/app/getting-started/project-structure): route/file conventions.
- [Next.js TypeScript](https://nextjs.org/docs/app/api-reference/config/typescript): native TypeScript support and generated route helpers.
- [React list rendering](https://react.dev/learn/rendering-lists): stable keys from data, not indexes or random values.
- [React conditional rendering](https://react.dev/learn/conditional-rendering): readable, explicit conditional UI.
- [Tailwind responsive design](https://tailwindcss.com/docs/responsive-design): mobile-first responsive variants.
- [Tailwind dark mode](https://tailwindcss.com/docs/dark-mode): explicit theme switching.
