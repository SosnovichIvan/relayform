## Context

В Figma уже есть Foundations с тёплой нейтральной палитрой, жёлтым primary action, коралловым signal-акцентом и типографикой Inter. Страница `01 • Landing` пуста.

## Goals / Non-Goals

**Goals:**

- Быстро дать два визуально разных направления для выбора.
- Показать оба направления в Light и Dark без дублирования дизайн-системы.

**Non-Goals:**

- Адаптивность, интерактивные прототипы, полный лендинг, код и новые UI-компоненты.

## Decisions

- Создать две desktop-композиции на одной Figma-странице: «Signal flow» с акцентом на мгновенную доставку и «Verification first» с акцентом на доверие к контакту. Это позволяет сравнить продуктовые сообщения, а не только декоративные стили.
- Для каждой композиции показать соседние Light/Dark карточки. Альтернатива — отдельные большие фреймы — отклонена: она замедляет быстрый выбор.
- Использовать существующие Figma variables и text styles. Новые токены не создаются, поскольку задача исследовательская.

## Risks / Trade-offs

- [Эскизы могут быть слишком поверхностными для реализации] → после выбора создать отдельный OpenSpec change на детальную проработку и адаптивность.
- [Малый размер может скрыть проблемы сложной страницы] → оценивать только композицию, сообщение и тему, не production-ready детали.

## Migration Plan

Изменения ограничены Figma. Откат — удалить выбранные/невыбранные эскизы по идентификаторам после создания следующего change package.
