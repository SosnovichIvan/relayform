## Why

The confirmation-email editor needs a visual contract for the letter that a recipient receives. Without a preview, users cannot verify hierarchy, Relayform attribution or the current theme before saving a template.

## What Changes

- Add a confirmation-email preview to the Cabinet email editor in Figma.
- Render the same email layout in Light and Dark theme; only the theme and editable copy vary.
- Include the Relayform brand, confirmation CTA, landing-page link and an unobtrusive note that the message was created with Relayform.

## Impact

- Figma Cabinet Light/Dark editor references.
- User-cabinet design specification and project design context.
- No e-mail generation, theme-detection, sending or frontend code.
