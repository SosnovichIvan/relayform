## Why

Команда выбрала направление `B / Verification first`. Нужен первый цельный desktop-лендинг, который последовательно раскрывает верификацию e-mail и телефона, а не только его первый экран.

## What Changes

- Удалить из Figma невыбранный эскиз `A / Signal flow`.
- Сохранить компактный эскиз `B / Verification first` как референс выбранного направления.
- Собрать цельный desktop-лендинг на странице `01 • Landing` в светлой и тёмной темах.
- Использовать утверждённые variables, палитру и типографику Inter.
- Не добавлять адаптивные варианты, код, интерактивный прототип или новые продуктовые обещания вне утверждённого контекста.

## Capabilities

### New Capabilities

- `marketing-verification-landing`: Цельный desktop-лендинг Relayform, объясняющий верификацию контактов в Light и Dark.

### Modified Capabilities

- Нет.

## Impact

- Figma-файл Relayform, страница `01 • Landing`.
- `.ai/context/project-context.md` и данный OpenSpec change package.
- Исходный код и API не затрагиваются.
